1. 课程研究对象

课程研究内容：无线电通信系统中与高频信号处理有关的基本单元电路。

输入变换器 → 发送设备 → 传输信道 → 接收设备 → 输出变换器

课程重点关注 发送设备 和 接收设备，因为它们直接处理高频信号。

高频频段：本课程所称“高频”为 3 MHz ~ 30 MHz，即 HF 段，对应波长 100 m ~ 10 m。

单元电路常见位置主要作用
高频小信号放大器接收机前端放大微弱高频信号
高频功率放大器发射机末级输出足够的高频功率
选频回路收/发设备选出目标频率，滤除噪声

这些电路共同依赖的基础就是 LC 串/并联谐振回路，因此本章先讲高频基础电路。

2. 基础概念

集总元件与集总电路

“几种元件”是语音转写错误，正确为 集总元件。当电路尺寸远小于工作波长时，可把 R、L、C 的参数看成集中在一个点上。3~30 MHz 波长较长，一般电路仍可用集总模型。

无源与有源

无源元件没有内部电源，不向电路提供功率，例如 R、L、C；有源元件能提供能量或增益，例如晶体管、运算放大器。

“特性”指什么

在本课程中，“特性”不是固定值，而是 两个或多个物理量之间的关系。例如幅频特性是幅度与频率的关系，阻抗特性是阻抗与频率的关系。

3. 电感线圈的高频特性

实际电感不是纯 L，而是 有损电感。它有两种等效形式：串联模型（L 与 R₀ 串联）和并联模型（L 与 G₀ 并联）。

品质因数 Q₀

Q₀ = ω₀ × (储能 / 平均损耗功率)
串联模型电流相同，因此：
Q₀ = (I²·ω₀L) / (I²·R₀) = ω₀L / R₀

重点：Q₀ = ω₀L / R₀。Q 越高，储能越强、损耗越小，选频特性越尖锐。

阻抗与导纳

串联模型：Z = R₀ + jωL
并联模型：Y = G₀ + 1/(jωL) = G₀ − j/(ωL)
阻抗角：φ = arctan(Im / Re)

4. 电容的高频特性

电容也有介质损耗、引线电阻等，可用串联模型（C 与 R₀ 串联）或并联模型（C 与 G₀ 并联）表示。

串联模型中容抗为 1/(ωC)，因此：
Q₀ = (1/(ω₀C)) / R₀ = 1/(ω₀C R₀)

重点：电容的 Q 值常达几千到几万，所以高频电路中一般把电容当作 理想无损元件；电感损耗通常不能忽略。

串联模型：Z = R₀ + 1/(jωC) = R₀ − j/(ωC)
并联模型：Y = G₀ + jωC

5. LC 串联谐振回路

5.1 阻抗表达式

Z = R₀ + jωL + 1/(jωC) = R₀ + j(ωL − 1/(ωC))

若串入负载 R_L，将 R₀ 换成 R₀ + R_L 即可。

5.2 谐振频率推导

串联回路阻抗模：
|Z| = √(R₀² + (ωL − 1/(ωC))²)
要使电流最大，必须让 |Z| 最小，即虚部为零：
ω₀L − 1/(ω₀C) = 0
解得：
ω₀ = 1/√(LC)　　f₀ = 1/(2π√(LC))

重点：串联谐振频率只由 L、C 决定，空载和有载情况下 f₀ 相同。

5.3 品质因数

空载：Q₀ = ω₀L / R₀ = 1/(ω₀C R₀)
有载：Q_L = ω₀L / (R₀ + R_L) = 1/(ω₀C(R₀ + R_L))

易错：接负载后耗能电阻增大，因此 Q_L < Q₀。

5.4 阻抗幅频特性

提出 R：
|Z| = R√(1 + ((ωL − 1/(ωC))/R)²)
由 Q = ω₀L/R = 1/(ω₀CR) 得：
ωL/R = Q(ω/ω₀)，　1/(ωCR) = Q(ω₀/ω)
因此：
|Z| = R√(1 + Q²(ω/ω₀ − ω₀/ω)²)
当 ω = ω₀ 时，|Z| = R 最小。

5.5 三条特性

  • 阻抗幅频：ω₀ 处 |Z| 最小，呈 V 形凹陷。
  • 阻抗角：ω = ω₀ 时 φ = 0（阻性）；ω > ω₀ 时 φ > 0（感性）；ω < ω₀ 时 φ < 0（容性）。
  • 电抗：X_L = ωL 为过原点直线，X_C = −1/(ωC) 为双曲线，交点为 ω₀。

6. LC 并联谐振回路

并联谐振有两种画法：形式 A（R₀ 与 L 串联后再与 C 并联）和 形式 B（G₀ 与 L 并联后再与 C 并联）。

6.1 导纳与谐振频率

形式 A 中，电感支路导纳：
Y_L = 1/(R₀ + jωL) = R₀/(R₀² + ω²L²) − jωL/(R₀² + ω²L²)
电容支路导纳：
Y_C = jωC
总导纳虚部：
B = ωC − ωL/(R₀² + ω²L²)
谐振时 B = 0：
ω₀C = ω₀L/(R₀² + ω₀²L²)
解得：
ω₀ = √(1/(LC) − R₀²/L²)

重点：令 ω₀∞ = 1/√(LC)、Q₀ = ω₀∞L/R₀，则 ω₀ = ω₀∞√(1 − 1/Q₀²)。实际并联谐振频率略低于理想值；高 Q 时 ω₀ ≈ 1/√(LC)。

6.2 谐振电阻

谐振时等效为纯电阻：
R_p = (R₀² + ω₀²L²) / R₀ = R₀(1 + Q₀²)
当 Q₀ ≫ 1 时：
R_p ≈ Q₀² R₀

重点：并联谐振电阻约为 Q₀²R₀。Q 越高，谐振电阻越大，选频越尖锐，也越便于阻抗匹配。

6.3 有载品质因数

并联接负载后总电导增大：G = G₀ + G_L，R_total = 1/G。

Q_L = R_total/(ω₀L) = ω₀C R_total

易错：并联回路 Q 为 R/X，串联回路 Q 为 X/R。原因：串联电流相同，功率比消去 I²；并联电压相同，功率比消去 U²。

6.4 并联谐振阻抗特性

  • 阻抗幅频：ω₀ 处 |Z| 最大，约为 R_p，偏离后迅速下降，呈山峰形。
  • 阻抗角：φ ≈ −arctan[Q_L(ω/ω₀ − ω₀/ω)]。
  • ω = ω₀：φ = 0（阻性）；ω < ω₀：φ > 0（感性）；ω > ω₀：φ < 0（容性）。

易错：并联回路在 ω₀ 两侧的阻抗角符号与串联回路正好相反。

7. 串/并联谐振对比表

8. 阻抗变换电路

8.1 串并联阻抗等效变换

并联支路阻抗：
Z_p = (jX_p·R_p)/(R_p + jX_p)
分子分母同乘 R_p − jX_p，实部、虚部分别等于 R_s、X_s。令 Q = |X_s|/R_s，得：
R_p = R_s(1 + Q²)
X_p = X_s(1 + 1/Q²)
当 Q ≫ 1 时：R_p ≈ Q²R_s，X_p ≈ X_s。

重点：此等效只在 同一工作频率 ω 下成立，因为电抗与频率有关。

8.2 变压器耦合连接

理想变压器无耗，功率守恒：

U₂²/R_L = U₁²/R_L′　⇒　R_L′ = (U₁/U₂)²R_L = (N₁/N₂)²R_L

8.3 自耦变压器耦合连接

R_L′ = ((N₁ + N₂)/N₂)²R_L

8.4 双电容分压耦合连接

C₁、C₂ 串联，负载与 C₂ 并联：

U₁/U₂ = (1/(ωC₁) + 1/(ωC₂))/(1/(ωC₂)) = (C₁ + C₂)/C₁
R_L′ = ((C₁ + C₂)/C₁)²R_L

8.5 接入系数 p 的统一公式

对变压器耦合定义：

p = 变换前匝数 / 变换后匝数 = N₂/N₁
物理量反射关系
电阻R_L′ = R_L/p²
电导G_L′ = p²G_L
电抗/感抗X_L′ = X_L/p²
电压U₁ = U₂/p
电流I₁ = pI₂

易错：p 的方向要明确，变换前 / 变换后搞反，电阻反射公式会变成倒数。

9. 功率传输与匹配网络

录音中特别强调：高频功率放大器输出端如果不做匹配，功率不能有效传输，严重失配甚至可能 烧坏功放。

匹配目标：

  • 纯电阻源：R_L′ = R_source。
  • 复阻抗源：Z_L = Z_source*（共轭匹配）。

具体 π 型、T 型、L 型匹配网络属于后续课程内容。

10. 一页速记

高频定义　3 MHz ~ 30 MHz（HF 段）
串联谐振　ω₀ = 1/√(LC)，谐振时 |Z| 最小
并联谐振　高 Q 时 ω₀ ≈ 1/√(LC)，谐振时 |Z| 最大
串联 Q　　ω₀L/R = 1/(ω₀CR)
并联 Q　　R/(ω₀L) = ω₀CR
串并联等效　R_p ≈ Q²R_s，X_p ≈ X_s（Q ≫ 1）
变压器反射　R_L′ = (N₁/N₂)²R_L = R_L/p²
电容分压反射　R_L′ = ((C₁+C₂)/C₁)²R_L
  • “高频”在课程语境中特指 3~30 MHz。
  • “特性”是关系，不是固定值。
  • 串联 Q 是 X/R，并联 Q 是 R/X，但 Q 的物理定义相同。
  • 串联谐振阻抗最小、电流最大；并联谐振阻抗最大。
  • 串联回路 ω>ω₀ 感性，并联回路 ω>ω₀ 容性。
  • 阻抗等效与反射变换都只在某一频率下成立。
