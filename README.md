## 1. 课程研究对象

**本课程研究：无线电通信系统中与高频信号处理有关的基本单元电路。**

无线电通信系统可拆成五部分：

```text
输入变换器 → 发送设备 → 传输信道 → 接收设备 → 输出变换器
```

其中与高频信号处理关系最密切的是：

- **发送设备**：把低频信号搬移到高频、放大并发射。
- **接收设备**：从天线接收的高频信号中选出所需信号并还原。

> [!IMPORTANT]  
> **高频频段**：本课程所说的“高频”通常指 **3 MHz ~ 30 MHz**，即无线电波段中的 **HF 段**。对应波长约为 **100 m ~ 10 m**。

本课程重点学习的单元电路：

| 电路 | 常见位置 | 主要作用 |
|---|---|---|
| 高频小信号放大器 | 接收机前端 | 放大微弱高频信号，噪声小、失真小 |
| 高频功率放大器 | 发射机末级 | 输出足够大的高频功率 |
| 选频回路 | 接收/发射设备 | 选出目标频率，滤除干扰和噪声 |

这些单元电路共同依赖的基础是 **LC 串/并联谐振回路**，因此本章先讲高频基础电路。

## 2. 先搞清楚几个基本概念

### 2.1 集总元件与集总电路

语音转写中的“几种元件/几种电路”，应为 **集总元件/集总电路**。

- **集总元件**：电阻、电感、电容这类元件，若其实际尺寸远小于工作波长，可把参数看成集中在一个点上。
- **集总电路**：由集总元件组成的、完成一定功能的电路。
- 在 3~30 MHz 高频段，波长较长，一般电路尺寸仍可看作集总电路；频率更高时需考虑分布参数。

### 2.2 无源元件与有源元件

- **无源元件**：没有内部电源、不能向电路提供功率，如 R、L、C。
- **有源元件**：能提供能量或功率增益，如晶体管、运算放大器等。
- 本章讨论的电感、电容是无源元件。

### 2.3 “特性”是什么意思

在高频电子线路中，**“特性”一般指两个或多个物理量之间的关系**。例如：

- 幅频特性：幅度与频率的关系。
- 阻抗特性：阻抗与频率的关系。
- 阻抗角特性：阻抗角与频率的关系。

## 3. 电感线圈的高频特性

实际电感线圈在高频下不是纯电感，而是一个 **有损电感**。常用两种等效电路：

1. **串联模型**：纯电感 L 与内阻 R₀ 串联。
2. **并联模型**：电导 G₀ 与电感 L 并联。

### 3.1 品质因数 Q₀

品质因数表征元件的 **储能与耗能之比**：

```text
Q₀ = ω₀ × (储能 / 平均损耗功率)
```

对电感串联模型，串联时电流相同：

```text
Q₀ = (I²·ω₀L) / (I²·R₀) = ω₀L / R₀
```

> [!IMPORTANT]  
> **电感串联模型的品质因数**：`Q₀ = ω₀L / R₀`。Q 越高，表示电感储能能力越强、损耗越小，选频越“尖锐”。

### 3.2 阻抗、导纳与阻抗角

电感串联模型：

```text
Z = R₀ + jωL
```

电感并联模型：

```text
Y = G₀ + 1/(jωL) = G₀ − j/(ωL)
```

阻抗角：

```text
φ = arctan(Im / Re)
```

## 4. 电容的高频特性

电容也存在介质损耗、引线电阻等，因此可等效为：

- **串联模型**：C 与损耗电阻 R₀ 串联。
- **并联模型**：G₀ 与 C 并联。

### 4.1 电容的品质因数

对串联模型，容抗为 `1/(ωC)`：

```text
Q₀ = (1/(ω₀C)) / R₀ = 1/(ω₀C R₀)
```

> [!IMPORTANT]  
> **电容的 Q 值通常很高**，可达几千到几万，因此在高频电路中常把电容近似为 **理想无损元件**。电感损耗一般不能忽略。

### 4.2 电容的阻抗、导纳

串联模型：

```text
Z = R₀ + 1/(jωC) = R₀ − j/(ωC)
```

并联模型：

```text
Y = G₀ + jωC
```

## 5. LC 串联谐振回路

### 5.1 电路模型

把有损电感等效为 R₀ + L，再与 C 串联：

```text
信号源 → R₀ → L → C → 地
```

串联回路总阻抗：

```text
Z = R₀ + jωL + 1/(jωC)
  = R₀ + j(ωL − 1/(ωC))
```

若再串入负载 R_L，则把 R₀ 换成 `R₀ + R_L` 即可。

### 5.2 谐振条件与谐振频率

**谐振**：外部激励频率等于回路固有频率时，受迫振荡幅度最大的现象。

串联谐振时希望 **|Z| 最小、电流最大**。由阻抗表达式：

```text
|Z| = √(R₀² + (ωL − 1/(ωC))²)
```

要使 |Z| 最小，必须让虚部为零：

```text
ω₀L − 1/(ω₀C) = 0
```

解得：

```text
ω₀ = 1/√(LC)
f₀ = 1/(2π√(LC))
```

> [!IMPORTANT]  
> **串联谐振频率**：`f₀ = 1/(2π√(LC))`。空载、有载情况下谐振频率不变，因为谐振只由 L、C 决定。

### 5.3 品质因数

- 空载品质因数：

```text
Q₀ = ω₀L / R₀ = 1/(ω₀C R₀)
```

- 有载品质因数：

```text
Q_L = ω₀L / (R₀ + R_L) = 1/(ω₀C(R₀ + R_L))
```

> [!IMPORTANT]  
> 串入负载后，耗能电阻增大，因此 **有载 Q 小于空载 Q**。

### 5.4 阻抗特性推导

把阻抗取模：

```text
|Z| = √(R² + (ωL − 1/(ωC))²)
```

提出 R：

```text
|Z| = R√(1 + ((ωL − 1/(ωC))/R)²)
```

利用 `Q = ω₀L/R = 1/(ω₀CR)`，可得：

```text
ωL/R = Q(ω/ω₀)
1/(ωCR) = Q(ω₀/ω)
```

所以：

```text
|Z| = R√(1 + Q²(ω/ω₀ − ω₀/ω)²)
```

当 `ω = ω₀` 时，括号内为 0，`|Z| = R`，取得 **最小值**。

### 5.5 三条特性曲线

1. **阻抗幅频特性**：在 ω₀ 处 |Z| 最小，呈“V 形”凹陷。
2. **阻抗角特性**：
   - ω = ω₀：φ = 0，呈 **纯阻性**。
   - ω > ω₀：φ > 0，呈 **感性**。
   - ω < ω₀：φ < 0，呈 **容性**。
3. **电抗特性**：
   - 感抗 `X_L = ωL`：过原点的直线。
   - 容抗 `X_C = −1/(ωC)`：双曲线。
   - 两者交点为 ω₀；交点以上 X > 0，交点以下 X < 0。

## 6. LC 并联谐振回路

并联谐振回路根据电感等效方式不同，有两种画法：

- **形式 A**：`R₀` 与 L 串联，再与 C 并联。
- **形式 B**：`G₀` 与 L 并联，再与 C 并联。

### 6.1 用形式 A 推导导纳

电感支路阻抗：

```text
Z_L = R₀ + jωL
```

其导纳：

```text
Y_L = 1/(R₀ + jωL)
     = R₀/(R₀² + ω²L²) − jωL/(R₀² + ω²L²)
```

电容支路导纳：

```text
Y_C = jωC
```

总导纳：

```text
Y = R₀/(R₀² + ω²L²) + j(ωC − ωL/(R₀² + ω²L²))
```

令虚部为 0：

```text
ω₀C = ω₀L/(R₀² + ω₀²L²)
```

整理：

```text
ω₀² = 1/(LC) − R₀²/L²
```

即：

```text
ω₀ = √(1/(LC) − R₀²/L²)
```

> [!IMPORTANT]  
> 若令 `ω₀∞ = 1/√(LC)`，且 `Q₀ = ω₀∞L/R₀`，则：  
> `ω₀ = ω₀∞√(1 − 1/Q₀²)`。  
> 因此实际并联谐振频率略低于理想频率；当 Q₀ ≫ 1 时，`ω₀ ≈ 1/√(LC)`。

### 6.2 谐振时的等效电阻

谐振时回路等效为一个纯电阻：

```text
R_p = (R₀² + ω₀²L²) / R₀
    = R₀(1 + Q₀²)
```

当 Q₀ ≫ 1 时：

```text
R_p ≈ Q₀² R₀
```

> [!IMPORTANT]  
> **并联谐振回路的谐振电阻约为 `Q₀²R₀`**。Q 越高，谐振电阻越大，选频特性越好，也越容易与放大器输出阻抗匹配。

### 6.3 有载并联谐振回路

并联接入负载 R_L 后，总电导增大：

```text
G = G₀ + G_L
R_total = 1/G
```

有载品质因数：

```text
Q_L = R_total/(ω₀L) = ω₀C R_total
```

> [!IMPORTANT]  
> **并联回路 Q 的形式是 R/X，不是 X/R**。  
> - 串联：电流相同 → `Q = I²X/(I²R) = X/R`。  
> - 并联：电压相同 → `Q = U²/X ÷ U²/R = R/X`。  
> 品质因数的物理定义并没有变，只是串联/并联时消去的公共量不同。

### 6.4 并联谐振的阻抗特性

1. **阻抗幅频特性**：在 ω₀ 处 |Z| 最大，约为 R_p，偏离 ω₀ 后迅速下降，呈“山峰形”。
2. **阻抗角特性**：

```text
φ ≈ −arctan[Q_L(ω/ω₀ − ω₀/ω)]
```

   - ω = ω₀：φ = 0，纯阻性。
   - ω < ω₀：φ > 0，呈 **感性**。
   - ω > ω₀：φ < 0，呈 **容性**。

> [!IMPORTANT]  
> 并联回路在 ω₀ 两侧的阻抗角符号与串联回路 **正好相反**，这是常考易错点。

### 6.5 串/并联谐振对比表

| 项目 | 串联谐振 | 并联谐振 |
|---|---|---|
| 谐振频率 | `1/(2π√(LC))` | 高 Q 时约 `1/(2π√(LC))` |
| 谐振时阻抗 | 最小，等于 R | 最大，约为 Q₀²R₀ |
| 谐振时表现 | 电流最大 | 回路两端电压最大（电流源激励时） |
| ω > ω₀ | 感性 | 容性 |
| ω < ω₀ | 容性 | 感性 |
| Q 公式 | `ω₀L/R = 1/(ω₀CR)` | `R/(ω₀L) = ω₀CR` |

## 7. 阻抗变换电路

### 7.1 串并联阻抗等效变换

已知串联支路 `R_s + jX_s`，要等效成并联支路 `R_p ∥ jX_p`。

并联支路阻抗：

```text
Z_p = (jX_p · R_p) / (R_p + jX_p)
```

分子分母同乘 `R_p − jX_p`，实部、虚部分别等于 R_s、X_s。

定义品质因数：

```text
Q = |X_s| / R_s
```

最终得到：

```text
R_p = R_s(1 + Q²)
X_p = X_s(1 + 1/Q²)
```

> [!IMPORTANT]  
> 当 **Q ≫ 1** 时：  
> `R_p ≈ Q²R_s`，`X_p ≈ X_s`。  
> 这是高频电路中把小串联电阻变换成大并联电阻的常用依据。

注意：该等效只对 **同一工作频率 ω** 成立，因为电抗与频率有关。

### 7.2 变压器耦合连接的阻抗变换

一次侧匝数 N₁，二次侧匝数 N₂，负载 R_L 接在二次侧。

由理想变压器无耗、功率守恒：

```text
U₂² / R_L = U₁² / R_L′
```

所以：

```text
R_L′ = (U₁/U₂)² R_L = (N₁/N₂)² R_L
```

### 7.3 自耦变压器耦合连接

若一次侧总匝数为 `N₁ + N₂`，负载仍接在 N₂ 两端：

```text
R_L′ = ((N₁ + N₂)/N₂)² R_L
```

### 7.4 双电容分压耦合连接

C₁、C₂ 串联，负载 R_L 与 C₂ 并联。利用电容分压：

```text
U₁/U₂ = (1/(ωC₁) + 1/(ωC₂)) / (1/(ωC₂)) = (C₁ + C₂)/C₁
```

所以：

```text
R_L′ = ((C₁ + C₂)/C₁)² R_L
```

### 7.5 接入系数 p 与统一反射公式

对变压器耦合，定义接入系数：

```text
p = 变换前匝数 / 变换后匝数 = N₂/N₁
```

则二次侧阻抗反射到一次侧：

| 物理量 | 反射关系 |
|---|---|
| 电阻 | `R_L′ = R_L / p²` |
| 电导 | `G_L′ = p² G_L` |
| 电抗/感抗 | `X_L′ = X_L / p²` |
| 电压 | `U₁ = U₂ / p` |
| 电流 | `I₁ = p I₂` |

> [!IMPORTANT]  
> 使用 p 时一定要先确认 **哪一侧是“变换前”、哪一侧是“变换后”**。p 的方向反了，电阻反射公式会变成倒数关系。

## 8. 功率传输与匹配网络（本章引出内容）

录音中强调：高频功率放大器输出端如果不做匹配，可能造成：

- 功率不能有效传输；
- 严重失配时功率反射，甚至 **烧坏功率放大器**。

匹配的目标是让负载阻抗（或其反射值）与信号源内阻满足最大功率传输条件：

- 纯电阻源：`R_L′ = R_source`。
- 复阻抗源：`Z_L = Z_source*`（共轭匹配）。

具体 π 型、T 型、L 型匹配网络属于后续课程内容。

```text
高频定义        3 MHz ~ 30 MHz（HF 段）
串联谐振        ω₀ = 1/√(LC)，谐振时 |Z| 最小
并联谐振        高 Q 时 ω₀ ≈ 1/√(LC)，谐振时 |Z| 最大
串联 Q           ω₀L/R = 1/(ω₀CR)
并联 Q           R/(ω₀L) = ω₀CR
串并联等效        R_p ≈ Q²R_s，X_p ≈ X_s（Q ≫ 1）
变压器反射        R_L′ = (N₁/N₂)²R_L = R_L/p²

```

### 易错点提醒

- “高频”在课程语境中特指 3~30 MHz，不能无限扩展。
- “特性”是关系，不是某一固定值。
- 串联 Q 是 `X/R`，并联 Q 是 `R/X`，但 Q 的定义相同。
- 串联谐振阻抗最小、电流最大；并联谐振阻抗最大。
- 串联回路 ω>ω₀ 呈感性；并联回路 ω>ω₀ 呈容性。
- 阻抗等效变换和反射变换都是在某一频率下成立。

## 附录 A：Q 值的能量本质与推导

品质因数不是“随便把电抗除以电阻”，它的原始定义来自能量：

```text
Q = 2π × (回路最大储能 / 一个周期内损耗的能量)
  = ω₀ × (回路最大储能 / 平均损耗功率)
```

谐振时，电感与电容之间不断交换能量，回路总储能基本不变，电阻（或电导）持续耗能。因此 Q 越大，回路储存能量的能力相对损耗越强，谐振现象越“尖锐”。

### A.1 串联 RLC 回路的 Q 推导

设串联回路电流：

```text
i(t) = I_m cos(ω₀t)
```

电容电压滞后电流 90°：

```text
v_C(t) = (I_m / (ω₀C)) cos(ω₀t − π/2)
```

电感储能与电容储能：

```text
W_L(t) = ½ L i²(t)
W_C(t) = ½ C v_C²(t)
```

谐振时：

```text
1/(ω₀C) = ω₀L
```

所以两项储能系数相等，任一时刻总储能：

```text
W_total = W_L + W_C = ½ L I_m²
```

电阻平均损耗功率：

```text
P_avg = ½ I_m² R
```

代入 Q 的定义：

```text
Q₀ = ω₀ W_total / P_avg
   = ω₀ (½ L I_m²) / (½ I_m² R)
   = ω₀L / R
```

这就是串联回路 Q 为“电抗比电阻”的深层原因。

### A.2 并联 RLC 回路的 Q 推导

并联回路两端电压：

```text
v(t) = U_m cos(ω₀t)
```

电感电流滞后电压 90°：

```text
i_L(t) = (U_m / (ω₀L)) cos(ω₀t − π/2)
```

电容储能与电感储能：

```text
W_C(t) = ½ C v²(t)
W_L(t) = ½ L i_L²(t)
```

谐振时：

```text
1/(ω₀L) = ω₀C
```

总储能：

```text
W_total = W_C + W_L = ½ C U_m²
```

电导平均损耗：

```text
P_avg = ½ U_m² G
```

因此：

```text
Q₀ = ω₀ W_total / P_avg
   = ω₀ (½ C U_m²) / (½ U_m² G)
   = ω₀C / G
   = R/(ω₀L)
```

> [!IMPORTANT]
> 串联是“电流相同”导致 `Q=X/R`；并联是“电压相同”导致 `Q=R/X`。二者的原始定义完全相同，都是储能与耗能之比。

## 附录 B：谐振回路的选择性与通频带

### B.1 串联谐振的电流归一化曲线

谐振时电流：

```text
I₀ = U / R
```

任意频率下：

```text
I(ω) = U / |Z|
     = U / [R√(1 + Q²(ω/ω₀ − ω₀/ω)²)]
```

所以归一化电流：

```text
I/I₀ = 1 / √(1 + Q²(ω/ω₀ − ω₀/ω)²)
```

令失谐量：

```text
Δω = ω − ω₀
```

当 Δω 很小时：

```text
ω/ω₀ − ω₀/ω ≈ 2Δω/ω₀
```

因此：

```text
I/I₀ ≈ 1 / √(1 + (2Q Δω/ω₀)²)
```

### B.2 3 dB 带宽

定义带宽边界为电流下降到谐振值 `1/√2` 倍：

```text
1/√2 = 1 / √(1 + (2Q Δω/ω₀)²)
```

解得：

```text
2Q |Δf_3dB| / f₀ = 1
```

所以通频带：

```text
BW_3dB = f₀ / Q
```

> [!IMPORTANT]
> **Q 越高，通频带越窄，选择性越好**。有载时用 `Q_L`，因此负载越重，通频带越宽。

补充：单谐振回路的矩形系数（0.1 电平带宽与 0.707 电平带宽之比）理论值约为 9.95，远大于理想滤波器矩形系数 1，说明单个 LC 谐振回路的“矩形度”并不理想。

### B.3 并联谐振的归一化阻抗

并联回路总导纳可写成：

```text
Y = G[1 + jQ(ω/ω₀ − ω₀/ω)]
```

因此阻抗模：

```text
|Z| = 1/|Y|
    = R_p / √(1 + Q²(ω/ω₀ − ω₀/ω)²)
```

它与串联电流归一化曲线形状相同，因此通频带同样近似为：

```text
BW_3dB ≈ f₀ / Q
```

区别在于：

- 串联谐振：电压源激励时，谐振时 **电流最大**。
- 并联谐振：电流源激励时，谐振时 **回路两端电压最大**；若用理想电压源激励并联回路，则谐振时 **电源输出电流最小**，因为回路阻抗最大。

## 附录 C：串并联阻抗等效的完整代数推导

设并联支路为 `R_p` 与 `jX_p` 并联：

```text
Z_p = (jX_p R_p) / (R_p + jX_p)
```

分子分母同乘 `R_p − jX_p`：

```text
Z_p = (jX_p R_p (R_p − jX_p)) / (R_p² + X_p²)
```

因为 `j·(−j) = 1`，展开：

```text
Z_p = (jX_p R_p² + X_p² R_p) / (R_p² + X_p²)
```

所以：

```text
Re(Z_p) = X_p² R_p / (R_p² + X_p²)
Im(Z_p) = X_p R_p² / (R_p² + X_p²)
```

若要等效成串联支路 `R_s + jX_s`，令实部、虚部分别相等：

```text
R_s = X_p² R_p / (R_p² + X_p²)
X_s = X_p R_p² / (R_p² + X_p²)
```

两式相除：

```text
X_s / R_s = R_p / X_p
```

令品质因数：

```text
Q = X_s / R_s = R_p / X_p
```

于是 `R_p = Q X_p`。代回实部公式：

```text
R_s = Q X_p / (1 + Q²) = R_p / (1 + Q²)
```

代回虚部公式：

```text
X_s = Q² X_p / (1 + Q²)
```

反解得到常用形式：

```text
R_p = R_s(1 + Q²)
X_p = X_s(1 + 1/Q²)
```

当 `Q ≫ 1` 时：

```text
R_p ≈ Q² R_s
X_p ≈ X_s
```

> [!IMPORTANT]
> 这一步可以把“小串联电阻 + 小电抗”转换成“大并联电阻 + 几乎相同的电抗”，是高频放大器、谐振回路接入和阻抗匹配中的核心工具。

## 附录 D：最大功率传输定理推导

把信号源等效为戴维南源：

```text
Z_source = R_s + jX_s
Z_load = R_L + jX_L
```

回路电流模值：

```text
|I| = |V_s| / |(R_s + R_L) + j(X_s + X_L)|
```

负载获得的有功功率：

```text
P_L = ½ |I|² R_L
    = (½ |V_s|² R_L) / [(R_s + R_L)² + (X_s + X_L)²]
```

第一步，固定 R_L，令分母最小，应使电抗抵消：

```text
X_L = −X_s
```

此时：

```text
P_L = ½ |V_s|² R_L / (R_s + R_L)²
```

第二步，对 R_L 求导并令导数为 0：

```text
dP_L/dR_L = 0  →  R_L = R_s
```

因此最大功率传输条件为：

```text
Z_L = Z_source*
```

> [!IMPORTANT]
> 高频匹配网络通常由无损 L、C 构成，作用是：**先变换电阻大小，再用电抗抵消源/负载的虚部**，最终实现共轭匹配，而不是靠电阻消耗功率。

## 附录 E：高频元件损耗从哪里来

### 电感

- **导线直流电阻**：低频时即存在。
- **集肤效应**：频率升高后电流趋向导体表面，有效截面积减小，交流电阻增大。
- **邻近效应**：相邻导线中的高频电流相互影响，进一步增加损耗。
- **磁芯损耗**：有磁芯时存在磁滞损耗和涡流损耗。
- **分布电容**：线圈匝间电容在高频下不能忽略，超过自谐振频率后，电感甚至会呈现容性。

### 电容

- **电极与引线电阻**：等效为串联损耗电阻 R_s。
- **介质损耗与漏电**：等效为并联电导 G。
- 常用损耗角正切表示：

```text
tanδ = ωC R_s = G/(ωC) = 1/Q
```

因此优质电容的 `tanδ` 很小，Q 很大，高频近似中常可当作无损元件。
